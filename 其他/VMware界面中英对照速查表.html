VMware Workstation 界面中英对照速查表

版本 26.0.0 build-25388281官方无中文界面可打印

本表解决一件事：菜单看不懂，但照样能把虚拟机建出来、管起来。 新建虚拟机向导那一段（第 3 节）是重点。

先说结论：这个版本汉化不了（官方层面）。
你的 D:\VMware\messages\ 里只有 es（西）、fr（法）、ja（日）三种语言，没有 zh_CN。 VMware 官方中文最后停在 17.6.4，之后的 25H2 / 26.0 只保留英/法/西/日。
所以只能"换回旧版"或"外挂旧版语言包"——两条路的做法与风险见 第 7 节。
怎么用这份表：把本页在浏览器里打开（双击即可），拖到 VMware 窗口旁边，两边对照着操作。按 Ctrl+P 可以打印贴桌上。

3 · ★ 新建虚拟机向导（重点：你正要做的这一步）

最关键的一个岔路口——向导第一屏问你"安装来源"（Install from），三个选项里：
  1. Installer disc 物理光驱
  2. Installer disc image file (iso) ← 选它会触发"简易安装"，会强行跳过 Ubuntu 安装向导，用户名被定成 ubuntu，这就是你前面几次失败的原因
  3. I will install the operating system later ← ★ 选这个！（"稍后安装操作系统"）它不让 VMware 插手，你就能走完整向导、自己填用户名
第 1 屏 Welcome
Typical (recommended) 典型（推荐） ｜ Custom (advanced) 自定义（高级）
Install from: 安装来源 —— 选下面第三项：
I will install the operating system later. 　→ 稍后安装操作系统
第 2 屏 Select a Guest Operating System（选择客户机操作系统）
Guest operating system: 客户机操作系统 → 选 Linux
Version: 版本 → 选 Ubuntu 64-bit
第 3 屏 Name the Virtual Machine（命名虚拟机）
Virtual machine name: 虚拟机名称 → 填 lrh（只影响 VMware 里显示的名字）
Location: 位置 → 想改存放目录点 Browse… 浏览
第 4 屏 Specify Disk Capacity（指定磁盘容量）
Maximum disk size (GB): 最大磁盘大小 → 60
Store virtual disk as a single file 存为单个文件 ｜ Split virtual disk into multiple files 拆分成多个文件（默认即可，别改）
Allocate all disk space now 立即分配所有磁盘空间 ← 不要勾（勾了会马上占满 60GB）
第 5 屏 Ready to Create（准备创建）
点 Customize Hardware…（自定义硬件）可以调内存/CPU，也可以等下再调。
Power on this virtual machine after creation 创建后打开电源 ← 先不勾，因为还没挂 ISO。
然后点 Finish 完成。

创建后：手动挂 ISO

VM → Settings…（虚拟机 → 设置）→ 左侧硬件列表点 CD/DVD (SATA)：
  • 右侧选 Use ISO image file: 使用 ISO 映像文件 → Browse… 选 ubuntu-22.04.5-desktop-amd64.iso
  • 勾上 Connect at power on 启动时连接 ← 必须勾
然后开机，就会进 Ubuntu 图形安装向导。

5 · 常见英文提示 / 弹窗

英文原文中文 & 该怎么办
This virtual machine might have been moved or copied. 「这台虚拟机可能被移动或复制过」→ 选 I Moved It（我移动了它）（选 I Copied It 会重新生成网卡 MAC 和 UUID）
Cannot connect to the virtual machine. 「无法连接到该虚拟机」→ 通常是有另一个 VMware 进程占着，或文件被锁
The virtual machine is busy. 「虚拟机正忙」→ 等它跑完，或在确认无重要的操作时用 Power Off
Insuficient permission to access file / Access is denied 「访问被拒绝」→ 用管理员身份运行 VMware，或检查文件是否只读
No 3D support is available from the host. 「宿主机不支持 3D」→ 无害，虚拟机设置里关掉 Accelerate 3D graphics 即可
VMware Tools is not installed / out of date 「VMware Tools 未安装 / 过旧」→ 不影响使用，装它能让屏幕自适应、剪贴板互通
The disk is full / low disk space 「磁盘已满」→ 要么给虚拟磁盘扩容，要么清理宿主磁盘
Are you sure you want to …? 「确定要……吗？」→ Yes 是 / No 否
Continue / Cancel / OK / Apply 继续 / 取消 / 确定 / 应用

Where are you?你在哪 → 时区，选 Shanghai
Who are you?★ 决定终端提示符的一页，重点看下面
★ "Who are you?" 这一页，四个字段的对应关系：
字段填什么决定终端里的哪一部分
Your namelrh只是显示名，怎么填都不影响登录
Your computer's namelrh主机名 → 提示符 @ 后面那个
Pick a usernamelrh登录名 → 提示符 @ 前面那个 ★★★

最容易错的地方：很多人只改了最上面的 Your name，没改下面的 Pick a username。
只改 Your name → 终端还是 ubuntu@ubuntu；两处都改成 lrh → 终端才是 lrh@lrh。

7 · 汉化的两条路（以及为什么我建议你现在先别急）

路 A：外挂 17.6.4 的语言包（保留当前 26.0 版本）

原理：VMware 的界面文字就是 messages\<语言>\ 这个目录里的 3 个文件，程序启动时按配置去加载。你现在的目录里已有 es / fr / ja，证明这个机制是活的 —— 缺的只是一个 zh_CN 目录。

  1. 搞到 VMware Workstation Pro 17.6.4 的安装包（官方中文的最后一版）。 官方下载要登录 Broadcom 账号（免费注册）：support.broadcom.com → VMware Workstation Pro → 选 17.6.4。
  2. 装到别处或直接解包，取出里面的 messages\zh_CN\ 文件夹（含 vmui-zh_CN.dll、vmware.vmsg 等 3 个文件）。
  3. 把它整体复制到 D:\VMware\messages\zh_CN\（需要管理员权限）。
  4. 编辑 C:\Users\lz\AppData\Roaming\VMware\preferences.ini，在最后一行加： 
    pref.locale = "zh_CN"
  5. 完全退出 VMware 再重开 → 界面变中文。
风险（必须知道）：那 3 个文件是 17.6.4 的版本，装到 26.0 的程序里，可能出现"部分菜单还是英文"或个别对话框乱码。
但它完全可逆：只要删掉 messages\zh_CN\ 目录 + 删掉那行配置，就回到原样。原有文件一个都不动。

路 B：整机降级到 17.6.4（官方原生中文）

最"正"，但代价最大：卸载 26.0 → 装 17.6.4。

⚠️ 对你不适合，原因是集群：你的项目集群三台虚拟机是在用资产，而新版创建的虚拟机硬件版本较高，旧版 VMware 可能打不开（会提示 hardware version 不支持）。 为了一个界面语言，去冒"集群打不开"的风险，不划算。

路 C（社区汉化包）—— 我不建议

网上那些"一键汉化包"多数不只是文字文件，而是替换/额外注入 DLL。别人往里改了什么都无法验证，属于典型的杀软高风险项。
如果一定要用，至少只取纯 zh_CN 语言文件夹，不要运行任何 .exe/.bat 安装器。

我的建议：先用这份对照表把"新建虚拟机 + 装 Ubuntu"这个流程走完（你已经卡在这里两次了，流程本身不难，只是看不懂按钮）。
等这套流程顺了，你要是还觉得英文界面别扭，我们再去搞路 A —— 那时你已经能分清"哪里是真需要中文"，而不是全面看不懂。
